# nuki-mcp

FastMCP 3.2 server for Nuki Smart Lock control via Home Assistant Bridge.

A tool to lock/unlock front door, buzz intercom opener, check battery
status, and execute multi-step entry sequences (buzz main door → unlock
apartment). Designed for Stroheckgasse, Vienna.

Requires Home Assistant with Nuki integration, HASS_URL and HASS_TOKEN.

Install docs: follow mcp-central-docs/standards/AGENT_INSTALL_REFERENCE.md
